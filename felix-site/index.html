Why this site is different

Dr. Liao is in the US, so sharing Taiwanese patient data with him crosses a border. Under Taiwan PDPA and newer AI-era rules, faces and voices are themselves identifiable. So nothing identifiable leaves Taiwan — data is transformed first.

Build rule

Enforce the packet limit at the API layer, not the UI — Felix's app should only ever receive the three watermarked packet items, never identifiable fields or excluded modalities. And Felix has no authoring/design rights: advisory only, telemedicine-compliant. The treating AMD owns and is responsible for the diagnosis, plan & device design.
